# Application Bancaire v1
 
Application de gestion bancaire full-stack, développée comme projet portfolio pour démontrer des compétences CRUD dans un contexte métier réaliste.
 
## Stack technique
 
- **Backend** : Spring Boot
- **DataBase** : PostgreSQL
- **Frontend** : React, Vite, TypeScript, Tailwind CSS
## Fonctionnalités
 
- Gestion des clients
- Gestion des comptes bancaires
- Gestion des cartes bancaires
- Gestion des transactions (dépôt, retrait, virement)
